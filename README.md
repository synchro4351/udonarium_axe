# Udonarium_Axe_tyoitashi

[Udonarium Axe](https://github.com/Xelltis/udonarium_axe)に、読みやすさや卓中の操作を助ける機能を少し足した非公式フォークです。

基本機能・使い方・サーバー構築については[公式の利用ガイド](https://xelltis.github.io/udonarium_axe/)と[公式README](https://github.com/Xelltis/udonarium_axe#readme)をご覧ください。ここでは公式との差分だけを紹介します。

[写真で見る機能紹介](docs/showcase/README.md)：公式Axeにない機能を11項目にまとめています。

## バージョンとソース

- **固定版：tyoitashi r10／Axe v1.68.0**：[ソース`d8d9c8d5`](https://github.com/synchro4351/udonarium_axe/tree/d8d9c8d51ec242f3e2d9de68b8712c85e696df08)
- **開発版：Axe v1.68.0対応**：[`codex/synwork-integration`](https://github.com/synchro4351/udonarium_axe/tree/codex/synwork-integration)
- [バージョン履歴](TYOITASHI_VERSIONS.md) · [変更内容と再利用用のコミット一覧](TYOITASHI_CHANGES.md)

このリポジトリの既定ブランチは紹介ページです。試す場合は上の固定ソースまたは開発ソースを選び、公式の手順に沿ってビルドしてください。既定ブランチの「Download ZIP」や公式の配布ZIPは、ここに記載した私家版の完成品ではありません。

## 非公式デモ

[試用サイト](https://udonarium-trial.synwork.work/)で固定版`tyoitashi r10`を試せます。実験的な機能を含むため、動作が不安定な場合があります。大切な卓データは手元へ保存してください。デモのソースは上記の固定コミット`d8d9c8d5`です。

## 公式Axeに入った機能

私家版で先に作った機能のうち、公式Axeに同じものが入ったものは公式の実装へ移し、保存済みのデータは引き継いでいます。カットインのフォント選択と話者の画像・名前・立ち絵合わせ、画像スタンプとリアクション、頭上の吹き出し、文字だけのログ、手札の受け渡しと引き継ぎ、共有メモの整形、ルビ、画像の取り込み時の編集がこれにあたります。使い方は公式の説明をご覧ください。

カード表面の文章機能は、公式Axe v1.48.0へ採用されました。[元の提案ブランチ](https://github.com/synchro4351/udonarium_axe/tree/feature/card-face-text)は参考資料として残しています。

## 読み上げを足した理由

チャットを目で追い続けることに負担がある人にも、卓の会話を追いやすくするために作りました。読み上げが常に必須というほどではなくても、音声が少し補助してくれると遊びやすい、という使い方を想定しています。

テキスト表示を置き換えるものではなく、必要な人が自分の端末で選べる補助機能です。ブラウザのSpeechSynthesisを使用するため、声の種類や品質は端末・ブラウザに依存します。

## 利用上の注意

- フォントと絵文字は端末にあるものを使うため、参加者のあいだで字形が異なる場合があります。
- YouTubeの自動再生や埋め込みは、ブラウザの設定や動画側の制限に左右されます。
- 人から渡されたカードには、渡した人のIDと名前がカードと一緒に保存されます。セーブデータを第三者へ配る際は気をつけてください。
- 実卓で使っていますが、すべての環境・機能の動作を保証するものではありません。既存のセーブZIPは元のファイルを残してお試しください。
