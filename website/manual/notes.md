# 共有メモ

テーブルに貼り付けて参加者と共有できるメモです。状況のメモやハンドアウトの掲示などに使えます。

<Shot src="notes" alt="テーブルに置かれた共有メモ。碑文の文面が書かれている" caption="クリックするとその場で本文を編集できます" />

## 共有メモを置く

テーブルの何もない場所を右クリックし、「共有メモを作成」を選ぶと、その位置にメモが現れます。

## 共有メモを操作する

共有メモを**右クリック**すると、操作メニューが開きます。主な操作:

- **編集** — 本文や表示形式を変える
- **コピー** — 複製を作る
- **寝かせる / 直立させる** — テーブルに対する向きを切り替える
- **固定** — 位置をロックする
- **削除** — メモを消す

## 本文の表示形式（通常／整形）

右クリックメニューの「編集」で開く画面で、本文の表示を「通常」と「整形」から選べます。最初は「通常」で、入力したとおりに表示されます。

「整形」にすると、行頭の記号で見た目が変わります。記号のあとには半角スペースを入れます。

| 入力                                       | 表示                                             |
| ------------------------------------------ | ------------------------------------------------ |
| `# `・`## `・`### `                        | 見出し（大・中・小）                             |
| `- `                                       | 箇条書き                                         |
| `1. `                                      | 番号付きの箇条書き                               |
| `> `                                       | 引用                                             |
| `` `文字` ``、` ``` ` だけの行で挟んだ部分 | コード。中の記号やルビの書き方も文字のまま出ます |

記号を覚えていなくても、編集画面の「見出し」「箇条書き」などのボタンで、選んだ行の頭に記号を入れられます。仕上がりは下のプレビューで確かめられます。テーブル上でメモをクリックして編集するときは、記号を含む元の文が表示されます。

メモにマウスを乗せたときのポップアップも整形して表示されます。通常のメモと違い、ポップアップの中では本文を書き換えられないので、編集画面かテーブル上で直してください。

整形でも、次のものは入力したまま表示されます。

- `*` や `_` による強調、`* ` で始まる箇条書き
- 表、リンク、画像、HTML
- URL（通常表示と違い、リンクになりません）
- `HP-1` や `2*3` など、行の途中の記号

ルビ（`|漢字<かんじ>` または `|漢字《かんじ》`）は普通の文で使えます。表示形式はメモと一緒に保存され、全員に同じ形式で見えます。公開範囲外の参加者には、どちらの形式でもモザイク表示になります。

## 固定について

固定したメモはドラッグで動かせなくなり、タイトルバーに鍵アイコンが表示されます。
誤って動かしたくない掲示物に向いています。固定中は編集もロックされるため、書き換えるときは固定を解除してください。

## 公開範囲

メモは、見せる相手を「全員 / 特定プレイヤー / GMのみ」から選べます。公開範囲外の参加者には、メモは卓上に残りつつ **本文がモザイク表示** になり内容は読めません。設定のしかたは [情報の公開範囲](/manual/disclosure) を参照してください。

他のオブジェクトについては [カード](/manual/cards)・[ダイス](/manual/dice) を参照してください。
