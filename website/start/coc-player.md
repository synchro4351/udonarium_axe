# はじめてのCoC（PL向け）

このページは、クトゥルフ神話TRPG（CoC）にPLとして参加する人が、招待リンクを開いてから最初の判定を振るまでを案内します。
いあきゃらで作った探索者を、そのまま持ち込めます。

<IntroHero />

::: tip 用意するもの

- パソコンのブラウザ（いちばん確かめてあるのはChromeです）
- GMからもらった招待リンク
- いあきゃらで作った探索者

:::

## 1. 部屋に入る {#join}

GMからもらった招待リンクを開きます。
アカウントの登録も、インストールも要りません。

1. 左上に**接続情報**が開きます。
2. **ニックネーム**を、卓で呼ばれたい名前に書き換えます。
3. **役割**は**PL**のままにしておきます。

<Shot src="/images/intro/join.webp" alt="接続情報のパネルで、ニックネームの欄をプレイヤーからしんくろに書き換え、役割のPLを確かめるアニメーション" width="760" caption="名前を変えたら、もう卓の中です" />

リンクを開いても入れないときは、[招待リンクで参加する](/start/join#stuck)を見てください。

## 2. コマを用意する {#piece}

### いあきゃらから取り込む

1. いあきゃらで自分の探索者のページを開き、キャラ出力の**ココフォリア駒出力**を押します。これでコマのデータがコピーされます。
2. Axeに戻り、左上の丸いボタンで**メニュー**を開きます。
3. **セーブ&ロード**、**キャラ取り込み**の順に押します。
4. 入力欄に貼り付けて（`Ctrl`＋`V`）、**取り込む**を押します。

<Shot src="/images/intro/import.webp" alt="左上のメニューからセーブ&ロード、キャラ取り込みと進み、コピーしたコマのデータを貼り付けて取り込むアニメーション" width="760" caption="テーブルの左上の隅に、自分のコマが出ます" />

名前・能力値・HP・MP・SAN、それにチャットパレット（技能の一覧）まで、まとめて入ります。

### コマを動かす

コマをつかんで、行きたい場所までドラッグします。
動かす場所の指示は、たいていGMから出ます。

<Shot src="/images/intro/move.webp" alt="テーブルの隅にあるコマをつかみ、書斎の絨毯の上までドラッグするアニメーション" width="760" caption="手を離した場所に、コマが止まります" />

## 3. 話す {#talk}

チャットは画面の左下にあります。

1. 入力欄の上の左端の欄で、発言者を**自分の探索者**に切り替えます。
2. 入力欄にセリフを打って、`Enter`を押します。

<Shot src="/images/intro/speak.webp" alt="発言者をプレイヤーから藤崎ことはに切り替え、セリフを打ってEnterで送るアニメーション" width="700" caption="探索者の顔と名前で、セリフが並びます" />

改行したいときは`Shift`＋`Enter`です。

## 4. 判定する {#roll}

技能の判定は、チャットパレットからワンクリックで振れます。

1. 自分のコマを右クリックして、**チャットパレットを表示**を押します。
2. 振りたい技能の行を、続けて**2回クリック**します。1回目で入力欄に入り、2回目で送られます。

<Shot src="/images/intro/dice.webp" alt="コマの右クリックからチャットパレットを開き、目星の行を2回クリックすると、チャットに判定の結果が出るアニメーション" width="1000" caption="成功・失敗はダイスボットが判定してくれます" />

「SANチェックをどうぞ」と言われたら、パレットの**SANチェック**の行を同じように振ります。
ダメージのように、パレットにない式を振るときは、チャットの入力欄に`1d6`のように打って`Enter`です。

::: tip 「成功」や「失敗」が出ないとき
入力欄の右の欄が「DiceBot」のままになっています。押して**クトゥルフ神話TRPG**を選びます（新しい第7版で遊ぶ卓なら、**新クトゥルフ神話TRPG**）。
どれを選ぶかは、GMに聞くのが確かです。
:::

## こんなときは？ {#faq}

### 音が大きい・小さい {#volume}

左上の**メニュー**から**表示**、**音の設定**の順に開きます。
BGM・効果音などの種類ごとに、つまみで大きさを変えられます。
ここで変えた音量は自分の画面にだけ効くので、ほかの人には影響しません。

<Shot src="/images/intro/volume.webp" alt="左上のメニューから表示、音の設定と開き、BGMのつまみを左へ動かすアニメーション" width="760" caption="行の左のボタンを押すと、その種類だけ消せます" />

### チャットを閉じてしまった {#chat}

左上の**メニュー**を開いて、**チャット**を押すと戻ります。

<Shot src="/images/intro/chat-reopen.webp" alt="チャットウィンドウを閉じたあと、左上のメニューのチャットを押して開き直すアニメーション" width="900" />

### 表情（顔の差分）を増やしたい {#faces}

1. 自分のコマを右クリックして、**詳細を表示**を押します。
2. **立ち絵**の**＋**を押し、**アップロード**から表情の画像を選びます。
3. 増えた立ち絵を選んで、**名前**（たとえば`笑顔`）をつけます。
4. 話すときは、セリフのあとに半角スペースを空けて`@笑顔`と書きます。

<Shot src="/images/intro/faces.webp" alt="キャラクターシートの立ち絵に笑顔の画像を足して名前をつけ、セリフのあとに@笑顔と書いて送ると、笑顔の立ち絵で話すアニメーション" width="1000" caption="@笑顔の部分は送られず、表情だけが切り替わります" />

入力欄の左の顔の下にあるつまみでも、表情を切り替えられます。
くわしくは[立ち絵コマンド](/manual/chat-syntax#立ち絵コマンド)にあります。

## 全部を覚えなくて大丈夫 {#next}

Axeにはたくさんの機能がありますが、全部を使いこなす必要はありません。
ほかに要る機能は、きっと卓のGMが教えてくれます。

困ったときは[困ったとき](/help/)を、もっと知りたくなったら[操作マニュアル](/manual/)を開いてみてください。
