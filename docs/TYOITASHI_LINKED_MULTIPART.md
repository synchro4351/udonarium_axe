# 連動する多部位キャラクター

既存のキャラクターを、部位ごとにHP・バフ・エフェクトを扱える複数のコマへ分けます。位置・サイズ・向きは一緒に変わります。

## 使い方

1. 画像を設定したキャラクターを右クリックし「部位に分ける」を選びます。キャラクターシートからも開けます。
2. 画像上で重ならない範囲を2つ以上囲み、モンスター名と部位名を入力します。
3. 「部位に分ける」を押します。各部位は元のキャラクターのデータを丸ごと引き継ぎます。不要なリソースは各部位のシートで削ってください。

元のキャラクターは削除せず墓場へ移します。選ばなかった画像部分は表示されません。小さな部位名・リソース・バフを部位の範囲に表示します。部位の連動を外す操作も右クリックにあります。

## 保存・同期

- 通常のキャラクターに同期属性（グループキー・モンスター名・部位名・画像範囲）を追加しています。新しいZIP形式はありません。
- 部屋保存では部位と連動情報を保存します。部位だけをコピー・単体読み込みした場合は連動を外し、既存のグループへ混ざることを防ぎます。
- 部位を墓場へ移しても他の部位は残ります。戻した部位は卓上の同じグループの位置に合わせます。
- 位置・高さ・回転・サイズ・固定を共通にします。HP・バフ・発言・ターゲットは各キャラクターの既存処理を使います。受信した移動を再配信し続ける処理はありません。
- 画像は通常の画像管理に登録し、元画像の秘匿状態を引き継ぎます。現在表示中の画像を分ける機能で、別の立ち絵を自動分割しません。

## 今回の範囲と制限

部位ごとの手番は既存のキャラクターとして扱います。モンスター全体をチャットで選び、部位を切り替える専用UI、騎手と馬のような異なる位置の連動、死亡部位の色抜きは今後の候補です。HPなどの項目名から不要データを自動削除しません。

画像範囲に合わせたエフェクト位置は、各閲覧者のカメラで計算します。通常の床上ビルボード表示を基準にしています。壁面・画像回転・多方向表示を組み合わせた特殊な表示は目視確認が必要です。
