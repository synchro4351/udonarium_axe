# カットイン編集の詳細を折り畳む

## 目的と使い方

最初に使う操作を残し、必要になった時だけ時間軸・位置や効果・表示の向きを開けるようにした。時間軸を閉じてもレイヤー一覧が残り、隠れたレイヤーも選べる。画像・文字・図形の追加、再生と停止、再生位置、取り消しとやり直し、文字とフォントの編集は閉じたまま使える。

- 「タイムライン」：キーフレーム・音・ポーズ・時間軸の拡大縮小。
- 「位置・動き・効果」：座標・大きさ・切り抜き・効果・アニメーション。
- 「表示の向き」：画面を囲んで使う場合の多方向表示。

表示の開閉は編集画面内だけの状態。データへ保存・同期しない。多方向表示の設定値そのものは、従来どおり端末の表示設定へ保存する。カットインの保存形式や再生権限を変えない。既存のシーンも書き換えない。

## 変更範囲

基点：公式Axe v1.59.0を含む私家版`17ba32be9c22fad3ccc313553f74aa203ae91355`。ブランチ：`codex/cutin-ui-disclosure`。

- シーン編集：時間軸の開閉をSignalで保持し、閉じている時は既存のレイヤー一覧を表示。上限を約3行分にしてスクロールできる。時間軸の要素が現れた時だけResizeObserverを接続し、消えたら解除。開閉後にプレビューの表示範囲を計測し直す。
- レイヤー設定と一覧：native details/summaryで詳細を折り畳む。開閉で入力値を消さない。閲覧専用の入力欄は、属性だけでなくNgModelの無効状態へ揃えた。
- ja/en/koのラベル、シーン編集のテスト、ブラウザ検証、利用ガイド。

## 互換性と制限

閉じたままでも既存のキーボード操作は残る。詳細の表示状態は画面を閉じるとリセットする。個別の入力欄を減らす全面改装や初心者モードは含めない。文字の動きや書式の選択肢は今後の別変更で扱う。

公式へ移す場合は同じ編集コンポーネントへ適用する。既存の私家版にはキャラクター画像・文字単位の動きなどの追加があり、HTMLをそのまま置換せず、折り畳む範囲を公式の項目へ合わせる。共有メモ整形を含む基点から分岐したが、本変更の処理は共有メモに依存しない。AngularのSignals、既存のレイヤー一覧と計測処理を使用する。新しい依存パッケージはない。
