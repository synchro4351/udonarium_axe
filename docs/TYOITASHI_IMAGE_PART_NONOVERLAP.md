# 部位範囲の重なり禁止

## 仕様

部位コマの範囲選択で、既に選んだ範囲と重なる範囲を追加できないようにする。面積のある重なりはすべて対象で、一部の重なり、完全に含まれる範囲、同一範囲を拒否する。辺や角が接するだけなら許可する。

- 判定は画像内の元ピクセル座標で行う。縮小表示でも、ポインタ座標の変換後に比べる。
- 既存範囲の内側からはドラッグを始められない。範囲の辺上からは始められる。
- 重なる範囲をドラッグ中は枠が赤くなり、離すと追加されずに「範囲は重ねられません」と出る。次に有効な選択を始めると消える。
- 逆方向のドラッグ、マウス、タッチで同じ判定になる。
- 部位を消すと、その範囲は再び選べる。
- 作成処理（MultipartCharacterService）も同じ判定を通す。重なる指定は画像の切り抜きより前に拒否するため、一部だけ作られることはない。
- 処理中・編集不可・元画像の読み込み前は、従来どおり選択できない。

保存形式は変えない。連動移動や、部位を束ねる新しいキャラクターの扱いは未決のため含めない。

## 紹介文案

部位コマを作る範囲選択で、範囲が重なる指定を受け付けないようにしました。辺が接するだけなら選べます。重ねて選んでしまった時は短い案内が出て、消した部位の範囲は選び直せます。
