# 半角山括弧で入力するルビ

## 使い方

`|漢字<かんじ>` と入力すると、漢字の上に「かんじ」が出る。全角の `｜` と、従来の `|漢字《かんじ》` も使える。スタンプ一覧の「特殊記法」から挿入するルビは、半角山括弧になった。

チャット、通常・整形の共有メモ、カードの共通文字表示で同じ処理を使う。ノベルモードの文字送りも親文字と読み仮名を一緒に扱う。読み上げは読み仮名、頭上吹き出しは親文字を使う。HTMLログにはルビが付き、文字ログには `漢字《かんじ》` と残る。

## 記法の範囲

- 半角の `<` と `>` を使い、親文字と読み仮名を両方入れる。親文字の中に空白・山括弧・縦棒は入れない。
- 読み仮名の中の空白は使える。改行、縦棒、山括弧は使わない。空白だけの読み仮名や閉じ忘れは文字のまま残る。
- 縦棒のない数式や比較は変わらない。`1 < 2 > 0`、`2d6<=8`、絶対値の `|x|<3>` はルビにならない。
- 整形した共有メモのコード部分は、記号もルビもそのまま表示する。
- エフェクトを続ける場合は `|技<わざ> 《斬撃》` のように空白で区切る。新しい記法と従来の記法が重なる `|a<b>《c》` は、以前と同じく親文字 `a<b>`、読み仮名 `c` と解釈する。既存データの読み方を保つための優先順である。
- `|a<script>` のように新しい記法そのものに当てはまる文字列はルビになるが、読み仮名も本文もHTMLとして実行しない。画像・スクリプト・リンクを作る機能ではない。

## 変更範囲と依存

基点：`be4b77f460a902aafbede0858b5edcdcd9141124`。ブランチ：`codex/ascii-ruby`。

`domain/chat/ruby-notation.ts` に共通の読み取り処理を置き、表示、段階表示、読み上げ、ログ、吹き出しから使う。エフェクト命令とホットバーの見た目の判定も、この処理でルビの読み仮名を除外する。従来の `《…》` エフェクトの呼び出しは残す。

新しい依存パッケージ、保存形式、同期属性はない。チャットやメモは入力した文字列のまま保存・同期される。XMLの改行保持の修正を含む本流から分岐しているが、ルビの読み取り処理そのものは、その修正や文字アニメーションには依存しない。共有メモの整形表示には既存の限定Markdownの処理を使う。

新しい記法を知らない古い版では、半角山括弧のルビは記号を含む文字として見える。全員の表示を揃えるには同じ版を使う。従来の記法はこれまでどおり表示できる。
