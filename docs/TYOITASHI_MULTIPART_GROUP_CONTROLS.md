# 多部位の連動・コピー・名前

基点：`3d05f16cc5902c3e9d1faf60581b9bdd8ffe2086`（Axe v1.65.2基盤）。枝：`codex/multipart-group-controls`。

## 操作

- 複数のキャラクターを選び、右クリックから「連動させる」。最初のコマへ位置・サイズ・高さ・向きを合わせる。選んだコマが既に連動中なら、そのグループの部位も含める。
- 連動中のコマをコピーすると、全部位が別のグループとしてコピーされる。複数選択に同じグループの部位が含まれても、コピーは一組だけ。墓場の部位もコピーされ、墓場に残る。
- 一部だけコピーしたい場合は、連動を外してコピーし、必要なコマを選んで再び連動させる。切り抜き範囲と部位名は連動解除後も残る。
- 詳細画面の「全体名」は全グループ、「部位名」は開いた部位へ反映される。卓上には全体名を一つ、部位名を小さく表示する。

HP・バフは各キャラクターで独立する。連動で共有するのは位置などの既存項目だけ。コマ間の相対位置を保つ移動は今回含めない。

## 保存・同期

既存の`partGroup`を連動の識別に使い、`partRegion`を切り抜き範囲として分けて扱う。新しい保存形式は追加しない。部屋ZIPでは連動が残る。単体ZIPの読込と低レベルの単体コピーは元のグループへ加わらない。全体コピーには新しいグループキーを付ける。

名前の変更は通常のキャラクター名にも反映し、チャットや一覧の名前と食い違わないようにする。名前の表示は秘匿・視界・端末の表示設定に従う。
