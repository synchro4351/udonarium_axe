# 拡張子が欠けたZIP内画像の読み込み

外部ツールのZIPに`.undefined`など未知の拡張子のPNGが入っている場合、画像の先頭の署名からPNG・JPEG・GIF・WebPを判定して通常の画像管理へ登録します。画像が追加されなかった問題を直す限定的な変更です。

既知の拡張子の処理、画像の識別子、ZIPの保存形式、サイズ制限は維持します。SVG・HTMLなどのテキストを画像として自動判定しません。Workerと通常処理で同じ判定を使います。

- 基点：`6ba5a88e9f8323b2e4854f02fbef1b4e9e70af6e`
- ブランチ：`codex/archive-image-mime`
- 対象：mime-type、ZIP展開のWorkerと通常経路、テスト
- 多部位機能に依存しない修正です。公式へ移す場合もZIP展開の既存構造に合わせて確認してください。
- README掲載文案：一部の外部ツールで拡張子が欠けたZIP内の画像を読み込めるようにしました。
