## 今回の候補が取り込まれた後

- [x] カットインの見本から「いいね！」「💐」「❤」「ガーン」「Critical!」「Fumble!」「勝利！」「SANチェック」「Level UP」「Quest Clear」「論破」「おしまい」を一つずつ作り、背景が透けること、文字が読めること、動きが意図に合うことを確認する。通常は約1〜3秒、「おしまい」は約4秒。絵文字は端末のフォントで見た目が変わる可能性がある。
- [x] ❤と💐の通常版・円小さめ版を見比べ、文字と円の大きさを確認する。「ガーン」は上から入って下へ、「勝利！」と「Level UP」は上へ退場し、「おしまい」はゆっくり入退場することも見る。
- [x] 手札の公開ボタンを一度押しただけでは公開されず、確認操作で公開されることを確認する。公開中の表示が見落としにくいか、非公開に戻す操作がすぐ分かるかも見る。
- [x] 別の参加者として手札一覧を開き、公開中の人は表面、非公開の人は裏面が一覧に出ることを確認する。所有者が非公開に戻すと表面が消えることも見る。
- [x] 自分のカードを手札一覧の相手欄へドラッグして渡せることを確認する。別のウィンドウを上に重ねた場合は、奥の相手欄へ渡らないことも見る。
- [x] GMとして部屋設定の「他人の手札から引く」「カードを渡す」を別々に切り替える。それぞれ禁止中は画面上の操作と実際の移動が止まり、許可に戻すと使えることを二人以上で確認する。GM以外は設定を変えられないことも見る。
- [x] カードを手札から場へドラッグし、離した位置で表・裏を選べることを確認する。選択を取り消した場合は手札に残ることも見る。
- [x] 受け取ったカードの下に渡し主の顔画像、未設定なら代替アイコンが出ること、カードの表面を隠さないことを確認する。
- [x] 二人以上で山札へカードを足す・引く操作をし、枚数と厚さの変化を見比べる。遅れが残る場合は、参加端末とおおよその秒数を記録する。
