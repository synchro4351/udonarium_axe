# 次にユーザーが確認すること

更新日: 2026-09-25

この一覧は「何を見ればよいか」を忘れないための作業メモです。確認結果が届いた項目は日付と結果を書き足します。未確認は不合格を意味しません。

## 今回の候補が取り込まれた後

- [ ] カットインの見本から「いいね！」「💐」「❤」「ガーン」「Critical!」「Fumble!」「勝利！」「SANチェック」「Level UP」「Quest Clear」「論破」「おしまい」を一つずつ作り、背景が透けること、1〜3秒で終わること、文字が読めることを確認する。絵文字は端末のフォントで見た目が変わる可能性がある。
- [ ] 手札の公開ボタンを一度押しただけでは公開されず、確認操作で公開されることを確認する。公開中の表示が見落としにくいか、非公開に戻す操作がすぐ分かるかも見る。
- [ ] 別の参加者として「公開手札を見る」を開き、表面が見えること、閲覧画面を押してもカードが移動しないこと、所有者が非公開に戻すと表面が消えることを確認する。
- [ ] カードを手札から場へドラッグし、離した位置で表・裏を選べることを確認する。選択を取り消した場合は手札に残ることも見る。
- [ ] 受け取ったカードの下に渡し主の顔画像、未設定なら代替アイコンが出ること、カードの表面を隠さないことを確認する。
- [ ] 二人以上で山札へカードを足す・引く操作をし、枚数と厚さの変化を見比べる。遅れが残る場合は、参加端末とおおよその秒数を記録する。

## 継続して確認したいこと

- [ ] 手札公開の二端末同期と再接続後の非公開復帰。
- [ ] 受け渡し・渡し主表示・公開状態のセーブ再読込。公開状態は保存せず、渡し主情報はカードに保存する仕様。
- [ ] 弱い回線での実セッション時の動き。一般的な実卓採用試験の完了報告とは別の、個別機能の確認。

## 後で設計するもの

- カットインの切り抜き形状とカスタマイズ。今回の見本は既存のレイヤー編集機能を使い、切り抜き機能は増やしていない。
- キャラクター別手札とプレイヤーのひも付け。現在の手札は参加者単位。
