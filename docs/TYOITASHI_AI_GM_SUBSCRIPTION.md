# AIのGMをサブスクで動かす（ちょいたし）

AI連携パネルの**GMを任せる**のタブは、Claude APIのキーで動かすと、使った分だけ料金がかかります。
Claude Pro・Maxのサブスクで動かすときは、Claude CodeからAI連携（MCP）でつなぎ、同じタブからAIに番を渡します（公式v1.81.0から）。
このページはその手順です。ちょいたし版のサイト（udonarium.synwork.work・udonarium-room.synwork.work）で使う前提で書いています。

## APIのキーで動かすときとの違い

|                    | APIのキー（`gm`のブリッジ）                      | Claude Code（このページ）                       |
| ------------------ | ------------------------------------------------ | ----------------------------------------------- |
| 料金               | APIのキーで、使った分だけ                        | Pro・Maxのサブスクの範囲内                      |
| 始め方・止め方     | **GMを任せる**のタブ                             | タブで**始める**を押し、Claude Codeでも始める   |
| 使う額の上限       | パネルで決める（5ドルなど）                      | サブスクの利用枠（5時間ごとの上限など）で止まる |
| AIの番が来るとき   | パネルで選ぶ（発言ごと・呼ばれたときだけ・手番） | 同じくパネルで選ぶ                              |
| モデル・考える深さ | パネルで選ぶ                                     | Claude Codeの側で選ぶ                           |

長い卓では、サブスクの利用枠に届いてAIが止まることがあります。止まったら、枠が戻るのを待って続きを頼みます。

AIは`wait_for_turn`という道具で自分の番を待ち、番が来たときだけ動きます。番が来ないあいだは、ほとんど利用枠を使いません。

部屋のチャットは、部屋にいる誰でも書けます。AIに盤面を変えることを広く許すときは、部屋のチャットではなく、Claude Codeの入力欄から伝えます。

## 用意するもの

- Claude Code（端末で動くClaude）。Pro・Maxのアカウントでログインしておきます
- Node.js 22以上（ブリッジを動かすため）
- AIの席を開くためのブラウザのプロファイル（人のGMやPLとは別のもの）

## 1. Claude Codeをサブスクでログインする

1. 端末で`claude`と打って起動し、`/login`でPro・Maxのアカウントを選びます。
2. `/status`で、ログインの方法がサブスクのアカウントになっているかを確かめます。

環境変数`ANTHROPIC_API_KEY`が設定されていると、Claude CodeはAPIのキーを使い、使った分の料金がかかります。
サブスクで動かすときは、この変数を消してから起動します。

## 2. ちょいたし版のブリッジを入れる

ちょいたし版は公式より道具（カード・行動順・マップマスク・ホットバーのひな形など）が多いので、公式のブリッジとはつながりません。
ブリッジは、つなぐサイトと同じ版のものを使います。

1. ちょいたし版のサイトで部屋を開き、FABメニューの**AI連携**を押します。
2. パネルの案内にあるリンクから`axe-mcp.mjs`を落とし、分かりやすい場所に置きます（例：`C:/Users/名前/axe/axe-mcp.mjs`）。
3. 端末で次を打ち、Claude Codeにブリッジを登録します。パスは置いた場所に合わせます。

```sh
claude mcp add axe -- node C:/Users/名前/axe/axe-mcp.mjs
```

`claude mcp list`の一覧に`axe`が出れば登録できています。
ちょいたし版のサイトはブリッジが初めから知っているので、`--allow-origin`は要りません。

サイトを更新したときは、ブリッジも落とし直して同じ場所に上書きします。
版が合わないと、パネルに「……とこのAxeの版が合いません」と出ます。

## 3. AIの道具を毎回尋ねられないようにする

AIは道具を何十回も使います。そのたびに許可を尋ねられないよう、作業用のフォルダを1つ作り、その中に`.claude/settings.json`を置きます。

```json
{
  "permissions": {
    "allow": ["mcp__axe"]
  }
}
```

`mcp__axe`は、ブリッジの道具をすべて許します。AIにできることは、Axeのパネルの**AIに許すこと**と席の役割で決まるので、ここで許しても席にできないことはできません。
このフォルダで`claude`を起動します。

## 4. AIの席を用意する

1. AI用のブラウザのプロファイルで部屋に入り、名前を「AI GM」などにします。
2. AIにGMを任せるときは、その席を部屋のGMにします。
3. その席でAI連携のパネルを開き、**AIに許すこと**を**書くことも許す**にして、**つなぐ**を押します。

## 5. 始める

1. AIの席のAI連携パネルで、**GMを任せる**のタブを開きます。
2. 指示（シナリオや進め方）、出番（発言ごと・呼ばれたときだけ・手番など）、聞くタブを決めて**始める**を押します。
3. Claude Codeで次を打ちます。

```text
/mcp__axe__run_ai_gm
```

2と3はどちらが先でもかまいません。AIは番が来るまで待ち、番が来ると、そのあいだに起きたことと指示を受け取って、発言・ダイス・演出で応えます。
プレイヤーのキャラクターの行動はAIが決めず、プレイヤーに尋ねます。
タブの**止める**で、AIに番が回らなくなります。

### タブを使わずに動かすとき

`/mcp__axe__run_session`と打つと、AIは手引き（`axe://guide/run-session`）に沿って、部屋で起きたことを自分で待ち受けて応えます。
出番をパネルで決められないかわりに、Claude Codeへの頼み方だけで役目を変えられます。誰も話さない時間も、待ち受けを繰り返すたびに利用枠を少しずつ使います。

### 人のGMの補佐（サブマスター）にするとき

人のGMとは別に、AIの席もGMにします。**GMを任せる**のタブで出番を「呼ばれたときだけ」にするか、`/mcp__axe__run_session`で手引きを読ませたあと、次のメッセージで役目を言葉で絞ります。

```text
あなたはサブマスターです。メインのGMは「〇〇」です。
名前を呼ばれたときと、ささやきで頼まれたときだけ応えてください。
それ以外はチャットを読んで待ち、場面を進めないでください。
頼まれたら、NPCの発言、ダイス、BGMやエフェクトの演出、マップマスクやメモの用意を手伝ってください。
```

GMの席は2つあっても動きます。ただし、2人が同時に場面を動かすと混乱するので、進行はメインのGMが持ちます。

### ホットバーを頼むとき

ホットバーは1人ずつのものなので、AIはプレイヤーのホットバーを直接は変えません。
プレイヤーがチャットで「詠唱と魔法攻撃と炎のエフェクトを1つのホットバーにまとめて」のように頼むと、AIがホットバーのひな形をチャットに出します。
ひな形の下の**自分のホットバーに取り込む**を押すと、自分のホットバーの空いているページに入ります。
人が作ったページも、ホットバーを右クリックして**このページをチャットで配る**で、ほかの人に渡せます。

## 6. 終わる

1. **GMを任せる**のタブで**止める**を押します。
2. Claude CodeでAIに「終わります」と伝えるか、Escで止めます。
3. Axeのパネルで**切る**を押します。
4. Claude Codeを終了します。ブリッジもいっしょに止まります。

## うまくいかないとき

| 見えるもの                       | 直しかた                                                                                            |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| 料金がAPIで請求されている        | `ANTHROPIC_API_KEY`が設定されています。消してからClaude Codeを起動し直し、`/status`で確かめます     |
| 「……とこのAxeの版が合いません」  | ブリッジとサイトの版が違います。パネルのリンクから落とし直して上書きし、Claude Codeを起動し直します |
| 道具を使うたびに許可を尋ねられる | `.claude/settings.json`を置いたフォルダで起動していません                                           |
| AIが途中で止まった               | サブスクの利用枠に届いたか、Claude Codeの返事待ちになっています。画面を見て、続きを頼みます         |
| AIがBGMやカットインを使えない    | AIの席がGMになっていません                                                                          |
| 「AIが番を待っていません」       | Claude CodeでAIが番を待っていません。もう一度`/mcp__axe__run_ai_gm`と打ちます                       |

ほかのことは、公式の[AI連携（MCP）](../website/manual/ai-link.md)の「うまくいかないとき」を見ます。

## 気をつけること

AIは読んだ部屋の内容（チャット・シート・コマの名前など）をAnthropicに送ります。ほかの参加者の発言も送られるので、AIを入れることを参加者に知らせてから使います。
