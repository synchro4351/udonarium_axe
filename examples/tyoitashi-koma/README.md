# すぐ使えるコマのテンプレート

卓にそのまま置けるキャラクターコマのひな形です。`examples/tyoitashi-koma.zip`を卓に読み込むと3個まとめて追加されます。1個だけ使うときは、このフォルダのXMLを単体で読み込んでください。画像は入っていないので、置いたあとで詳細から好きな画像に替えてください。

- `koma-coc6-investigator.xml`（探索者（CoC6版））：クトゥルフ神話TRPG 6版の探索者シートです。HP・MP・SANのゲージ、8つの能力値、アイデア・幸運・知識の自動計算、主な技能の初期値が入っています。チャットパレットはダイスボットCthulhuの`CCB`（5%ルール）で全技能を並べてあり、`:SAN-1d3`のようにSANを減らすコマンドも入っています。非公式のファン製テンプレートです。
- `koma-npc.xml`（NPC）：その場かぎりのNPC用です。HPと立場・状態・メモだけの軽いシートで、コピーして増やす使い方を想定しています。
- `koma-counter.xml`（カウンター）：ラウンドや時間を数えるためのコマです。`カウント`のゲージをコマの上に出し、チャットパレットの`:カウント+1`や`:カウント=0`で操作します。ラベルとメモは自由に書き換えてください。

どれも通常のキャラクターXMLなので、読み込んだあとは普通のコマと同じように編集・保存できます。作り直すときは、リポジトリ直下で`node scripts/package-cut-in-examples.mjs`を実行するとZIPが更新されます。
