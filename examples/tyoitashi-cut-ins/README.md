# カットインの演出見本

この16個はtyoitashiで作成した追加の見本です。新しい卓に自動で配置されません。カットイン一覧の「見本16個のZIP」から保存し、通常の卓データと同じ方法でZIPを読み込むと、まとめて追加できます。1個だけ試す場合は「演出見本を追加」から選べます。

各XMLは既存のCutIn・シーン・レイヤーの保存形式です。画像・音声の外部素材、卓や参加者のデータは含めません。背景の図形と文字を使い、キャラクター用の見本は画像未指定でシルエットを表示します。絵文字と端末フォントの見た目は端末によって異なる場合があります。

XMLの出力元は`src/app/features/media/cut-in-list/cut-in-scene-templates.ts`（基点34140927の16個）です。ここに置いたXMLは配布用の編集可能なスナップショット。アプリで編集して保存したXMLに置き換えることもできます。

配布ZIPを作り直すには、既存の依存パッケージをインストールした後、リポジトリ直下で次を実行します。通常のアプリのビルドで自動再生成はしません。

```sh
node scripts/package-cut-in-examples.mjs
```

出力先：`src/assets/samples/tyoitashi-cut-in-examples.zip`。新しい保存形式や実行スクリプトではなく、通常のカットインXML16個のZIPです。本リポジトリのMITライセンスで再利用できます。
