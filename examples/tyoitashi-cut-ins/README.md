# カットインの演出見本

この16個はtyoitashiで作成した追加の見本です。アプリには同梱せず、新しい卓にも自動で配置されません。リポジトリ直下の`examples/tyoitashi-cut-ins.zip`をダウンロードし、通常の卓データと同じ方法でZIPを読み込むと、まとめて追加できます。1個だけ試す場合は、このフォルダのXMLを単体で読み込んでください。

各XMLは既存のCutIn・シーン・レイヤーの保存形式です。画像・音声の外部素材、卓や参加者のデータは含めません。背景の図形と文字を使い、キャラクター用の見本は画像未指定でシルエットを表示します。絵文字と端末フォントの見た目は端末によって異なる場合があります。

XMLの出力元だった生成コードは、アプリから外しました（基点34140927の16個）。ここに置いたXMLが編集可能な配布用のスナップショットです。アプリで編集して保存したXMLに置き換えることもできます。

配布ZIPを作り直すには、既存の依存パッケージをインストールした後、リポジトリ直下で次を実行します。通常のアプリのビルドで自動再生成はしません。

```sh
node scripts/package-cut-in-examples.mjs
```

出力先：`examples/tyoitashi-cut-ins.zip`。このフォルダのXML16個だけを、ファイル名順・固定の更新日時で収めます。同じXMLからは同じバイト列のZIPになります。新しい保存形式や実行スクリプトではなく、通常のカットインXMLのZIPです。本リポジトリのMITライセンスで再利用できます。
